## About The Project

This code is associated with the following manuscript: 

__Assessing the impact of absence of coordination in malaria intervention strategies: a modelling study__  
Younes Iggidr, Nick Ruktanonchai, Bilal Benhana, Valérian Turbé, Billy Bauzile, Abigail Ward, Justin Cohen, Emilie Pothin, Clara Champagne.

## Description of the repository

- **ODE_model.R** : Odin code modeling the ODE system used in the paper, using Odin library
- **utils.R** : useful functions to simulate ODE, compute metrics and plot figures.
- **Toy_example.R** : Simulation of the example of Figure 2 and computation of the metrics of this simulation.
- **uncertainty_sensitivity_tree.R** : Uncertainty analysis, sensitivity analysis and Decision tree construction.
- **scenarios_case_studies.R** : Simulations of the case studies shown in Figure 5.
